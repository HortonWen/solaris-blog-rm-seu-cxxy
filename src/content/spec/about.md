# 关于天钺 Solaris

**天钺（Solaris）** 是东南大学成贤学院（SEU-CXXY）的 RoboMaster 参赛战队。这里是我们战队的技术博客，记录训练、备赛与开发过程中的学习笔记与项目沉淀。

## 我们做什么

RoboMaster 机甲大师赛是一个多兵种、多学科交叉的机器人对抗赛，战队按职能分为四个方向：

- **机械组**：SolidWorks 结构设计与建模、装配出图、材料与工艺、传动与电机选型；
- **电控组**：STM32 嵌入式开发、CubeMX 工程、UART/CAN 通信、PID 控制；
- **硬件组**：电路设计（嘉立创 EDA）、元器件选型、电源与保护电路、焊接与调试；
- **视觉组**：Ubuntu/Linux 开发环境、C++ 与 OpenCV、装甲板识别、位姿解算、卡尔曼滤波。

## 博客内容

- **培训笔记**：整理自同济大学（SuperPower）RoboMaster 战队公开的招新培训视频与课件（B 站空间：https://space.bilibili.com/651837546），面向入队新生，按机械 / 电控 / 硬件 / 视觉四组整理，附完整配图与推荐学习路径；
- **战队沉淀**：备赛过程中的踩坑记录、代码片段与经验总结（持续更新）。
